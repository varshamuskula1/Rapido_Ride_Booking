# Rapido_Ride_Booking
Rapido Ride Booking This is a simple ride booking application built using Python and Tkinter. The application allows users to book a ride by entering their name, pickup location, and drop location. The application then assigns the closest available rider and calculates the fare based on the distance.

Features Book a ride by entering customer details. Calculate the distance and fare for the ride. Assign the closest available rider. Display ride details and progress.
